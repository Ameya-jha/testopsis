    The tracking library and models download from a CDN on first use, then run locally. The admin vault is an encrypted database stored in this browser only: it is sealed with your passcode (AES-256) and cannot be read without it. The face check adds a second gate but can be fooled by a good lookalike or video, so choose a passcode you can remember and nobody can guess. For background tracking use Chrome or Edge, pin this tab, and turn off Memory Saver for this site.
